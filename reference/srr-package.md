# srr: 'rOpenSci' Software Review 'Roclets'

Companion package to 'rOpenSci' statistical software review project
('rOpenSci' authors, 2021;
[doi:10.5281/zenodo.5556756](https://doi.org/10.5281/zenodo.5556756) ),
to facilitate documenting software compliance with statistical standards
using 'Roxygen2' 'roclets'.
